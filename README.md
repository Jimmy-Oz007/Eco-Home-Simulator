# WattWise

WattWise is a browser-based home energy management game developed as part of a sustainability and gamification project.

The goal is to help players understand the impact of their everyday electricity usage by turning energy-saving decisions into an engaging simulation experience.

## Features

- Manage household appliances
- Track electricity consumption
- Pay monthly utility bills
- Maintain household comfort
- Purchase energy-efficient upgrades
- Experience random energy-related events
- Learn real-world energy management concepts

## Technologies Used

- HTML5
- CSS3
- JavaScript
